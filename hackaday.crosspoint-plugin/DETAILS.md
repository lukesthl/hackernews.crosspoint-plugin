# Hackaday

Browse and search Hackaday on your reader, and save articles as plain text to read offline.

- **Lists:** Latest, Featured, Columns, News, Retrocomputing and Security, plus search.
- **Save an article:** select a post and it is saved to `/Hackaday` as a `.txt` file, without the comments or site navigation.
- **No setup:** no account, no API key, no companion app.

## Limits

- Titles with curly quotes or other special characters show them as HTML codes (for example `&#8217;`) in the list.
- Images, videos and embedded code widgets are not included in the saved text.
- Comments are not included.

## Privacy

Post lists and search come from Hackaday's own WordPress API (`hackaday.com`). Article text comes from the Jina Reader service (`r.jina.ai`), which receives the address of each article you save.
