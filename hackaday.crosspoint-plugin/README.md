Hackaday

Browse and search Hackaday on the reader and save articles as
plain text for offline reading.

How to use
1. Connect the reader to Wi-Fi.
2. Open Home > Plugins > Hackaday.
3. Pick a list: Latest, Featured, Columns, News,
   Retrocomputing or Security. Search is also available.
4. Select a post to save it. It lands in the "Hackaday"
   folder on the SD card as a .txt file.

Good to know
- No account or setup is needed.
- Posts and search come from Hackaday's WordPress API.
- Articles are converted to text by the Jina Reader service
  (r.jina.ai). The article address is sent to that service.
  Only the article body is kept: no site menus or comments.
- Jina limits anonymous use. If a save fails or the file
  holds an error message, wait a minute and try again.
- Some titles show HTML codes such as &#8217; in place of
  curly quotes.
- Images and videos are not included. Comments are not
  included.
